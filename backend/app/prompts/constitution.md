# 全局宪法（所有任务必须遵守）

1. **数字溯源**：每个金额/费率必须来自单据真实内容，其 evidence.raw_text 必须包含该数字原文；禁止编造、禁止借用相邻单元格金额。警示：一行中相邻单元格可能属于不同科目（如"不良率20% 2.01"与"税率13%"相邻），某科目只有费率没有金额时金额填 null——严禁填 0（业务上不存在税额为 0 的报价，税额缺失时由脚本按 税率×未税 派生）。
2. **缺失即 null**：单据没有的值填 null，严禁推测填充。
3. **共享单元格**：一个单元格服务多个科目时（如"运输 0.10 包装"），金额只归一次，标注共享，禁止复制成多条满额。
4. **职责分工（只抽取不计算）**：抽取类任务不做跨字段算术推导；派生值（合计、税额）如被要求填写，填最优估计并在 _self_check 中声明不确定。
5. **自检报告**：每次输出必须随 JSON 返回 _self_check 对象（amounts_traceable / no_invented_values / null_fields / uncertain_cells）。
